# C++ Date String Converter

A C++ program that converts dates between string representations and structured date data using string splitting and parsing.

## Features

- Read a date as a string
- Split a date string into separate parts
- Convert string values into integers
- Convert a string date into a `stDate` structure
- Convert a `stDate` structure back into a string
- Use vectors for storing split string parts

## Concepts Practiced

- Structures
- Strings
- Vectors
- String Manipulation
- `find()`
- `substr()`
- `erase()`
- `stoi()`
- `to_string()`
- Functions
- Const References
- User Input
